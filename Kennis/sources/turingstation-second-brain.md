# Source note

Source: https://turingstation.nl/bouw-een-second-brain-met-hermes-en-obsidian/

The accessible part of the article presents a second brain as an owned, queryable Obsidian vault operated with the CODE loop: Capture, Organize, Distill, Express. Its central promise is low-friction capture through Telegram/voice notes, with the agent handling classification and filing so the human can later retrieve and use the information.

It emphasizes that small resources such as books, places, and saved ideas compound over time when the agent can both store them and retrieve them in context. The article also stresses that the agent should preserve control and keep the data in a user-owned Markdown vault.
