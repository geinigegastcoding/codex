# SiteRoast PDF Export Implementation Plan

**Goal:** Add a real, private, client-ready PDF report download.

**Architecture:** Generate bounded A4 PDF bytes with `pdf-lib` in a pure audit export module. Serve them through a new owner-authenticated Next.js route and link it from the existing report header.

**Tech stack:** Next.js 16, TypeScript, Supabase, `pdf-lib`, Node tests, pypdf, Poppler.

---

## Task 1: Specify the PDF contract

**Files:**
- Create: `tests/reports/pdf-export.test.ts`
- Create: `lib/audit/export-pdf.ts`

1. Add a failing test that safely detects the missing PDF builder.
2. Define a representative audit fixture with enough issues to paginate and with unsupported Unicode input.
3. Require a `%PDF-` signature, readable metadata, A4 pages, and multiple pages.
4. Add a filename-sanitization contract.
5. Run the focused test and confirm the missing behavior is the only failure.

## Task 2: Build the bounded PDF generator

**Files:**
- Modify: `package.json`
- Modify: `package-lock.json`
- Create: `lib/audit/export-pdf.ts`

1. Add the stable `pdf-lib` dependency.
2. Implement PDF-safe text normalization and measured wrapping.
3. Implement A4 page creation, section drawing, automatic page breaks, and footers.
4. Render audit context, scores, severity mix, summary, actions, issues, and pages.
5. Show explicit notes if an issue or page limit is reached.
6. Run the focused tests until green.

## Task 3: Add the authenticated download

**Files:**
- Create: `app/api/audits/[id]/pdf/route.ts`
- Modify: `app/dashboard/reports/[id]/page.tsx`
- Modify: `docs/SCAN_ENGINE.md`

1. Mirror the Markdown route's authentication and owner-scoped audit lookup.
2. Return generated bytes with PDF content type and a safe attachment filename.
3. Add the PDF action to the report header.
4. Remove the stale PDF-placeholder limitation from documentation.

## Task 4: Verify content and layout

1. Run focused and full tests.
2. Run lint and production build.
3. Generate a representative PDF in `tmp/pdfs`.
4. Reopen with pypdf and assert metadata, page count, and representative extracted text.
5. Render all pages to PNG with Poppler and inspect for clipping, overlap, and illegible text.
6. Run npm audit and diff checks, then continue to the next improvement slice.
