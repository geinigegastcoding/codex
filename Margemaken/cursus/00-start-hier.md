# 00. Start hier

## Doel

Je eindigt met een eigen kopie van de template, een gekozen werkprobleem en een eerste testbestand.

## Het uitgangspunt

Een AI-systeem begint bij een taak die vaak terugkomt. De tool komt later. Schrijf daarom eerst op welk werk je wilt verkorten, welke informatie ervoor nodig is en wie het resultaat moet controleren.

## Stappen

1. Kopieer de map `Margemaken` naar een eigen werkmap.
2. Open `AGENTS.md`.
3. Maak een persoonlijke of bedrijfscontextnotitie zonder gevoelige gegevens.
4. Kies een taak die wekelijks terugkomt en maximaal een uur kost per uitvoering.
5. Verzamel drie echte, geanonimiseerde voorbeelden.
6. Noteer hoe je de huidige uitkomst beoordeelt.
7. Sla je eerste plan op in `plans/01-eerste-systeem.md`.

## Eerste opdracht

Vul dit in:

```text
Mijn taak:
Hoe vaak komt hij terug:
Wie gebruikt de uitkomst:
Welke input is nodig:
Wat mag de agent zelfstandig doen:
Waar controleert een mens:
Wanneer is de test geslaagd:
```

## Controle

Je plan is klaar wanneer de taak in een zin uit te leggen is, de input bestaat en de gewenste output een vaste vorm heeft. Kies een kleiner probleem wanneer je meer dan een paar alinea's nodig hebt om de scope uit te leggen.

## Scriptkader

Open met het probleem dat deelnemers herkennen. Laat de lege template in de editor zien. Vraag kijkers om een taak te kiezen die ze deze week echt drie keer uitvoeren. Eindig met het planbestand als eerste kleine oplevering.
