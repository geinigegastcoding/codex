# Cursus: bouw je eigen AI-systeem

Deze cursus leert deelnemers hoe ze een vaste werkruimte bouwen waarin een agent context kan lezen, terugkerend werk kan uitvoeren en output op een controleerbare plek kan opslaan.

## Voor wie

Voor ondernemers en kleine teams die wekelijks dezelfde informatie verzamelen, beoordelen, schrijven of doorzetten. Basiskennis van bestanden, VS Code en een terminal helpt. Programmeerervaring is geen vereiste.

## Leerroute

| Module | Resultaat |
| --- | --- |
| 00. Start hier | Een veilige kopie en een eerste doel |
| 01. Werkruimte | Een begrijpelijke Mainframe-structuur |
| 02. Kennis | Een vault die context en bronnen scheidt |
| 03. Skills | Een herhaalbare werkwijze met beslisregels |
| 04. Workflows | Een echte taak door de hele route |
| 05. Dashboard | Overzicht van voortgang en systeemgezondheid |
| 06. Veiligheid | Reviewpunten, privacy en grenzen |
| 07. Onderhoud | Een wekelijkse audit en herstelpad |
| 08. Eigen systeem | Een capstone die je kunt demonstreren |

## Definition of done

Aan het einde heeft een deelnemer:

- een eigen kopie van de structuur;
- minimaal vijf bruikbare contextnotities;
- een skill voor een terugkerende taak;
- drie geteste voorbeelden;
- een dashboard met eigen voortgang;
- een reviewstap voor risicovolle output;
- een korte demonstratie en onderhoudsplan.
