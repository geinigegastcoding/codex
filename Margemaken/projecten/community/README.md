# Community template

Deze map vertaalt de leeromgeving naar vaste plekken voor deelnemers.

- `start-hier.md` - eerste login en eerste werkende output.
- `werkwijze.md` - weekritme en vragen stellen.
- `showcase.md` - resultaten en leerpunten delen.
- `vragen.md` - vraagformat voor hulp.
- `live-sessies.md` - voorbereiding en opvolging van sessies.
