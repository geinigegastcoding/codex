# Kennis

Dit is de lokale contextlaag van het AI-systeem. De vault is bewust leeg gestart. Voeg hier eigen, controleerbare informatie toe en houd de bronstatus zichtbaar.

Start bij [[00-authority]], daarna [[01-navigation]] en [[02-capture-guide]]. De agent leest de relevante context voordat hij een antwoord of bestand maakt.

## Hoofdregels

- `company/` bevat bedrijfscontext.
- `personal/` bevat persoonlijke context.
- `sources/` bevat externe bronnotities.
- `queries/` bevat herbruikbare antwoorden en syntheses.
- `logs/` bevat onderhouds- en werksgeschiedenis.
- `_archive/` bewaart verouderde inhoud voor controle.
