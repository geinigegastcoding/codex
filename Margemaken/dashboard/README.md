# Dashboard template

Een zelfstandige Vite/React-template voor het AI-systeem. De UI gebruikt de lichte Magisdata-stijl: `#fbfcff`, wit, zacht blauw en indigo `#4f58ff`.

## Starten

```powershell
npm install
npm run dev
```

## Controleren

```powershell
npm run typecheck
npm run build
```

## Wat je aanpast

- Vervang demo-data in `src/App.tsx` door data uit je eigen workflow.
- Houd de navigatie klein totdat echte gebruikers een extra view nodig hebben.
- Verplaats groeiende datasets later naar een aparte datafile of API.
- Behoud de demo-disclosure zolang de waarden niet aan een echte bron gekoppeld zijn.
