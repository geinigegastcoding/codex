# Brief: The AI privacy switch most tools hide

- **Topic:** How to evaluate whether a local AI tool is actually private
- **Viewer:** Practical AI user considering local software
- **Exact promise:** Learn a three-part data-flow check: endpoint, storage and telemetry
- **Afterward the viewer can:** Audit the basic privacy path of an AI tool without trusting the word “local”
- **Why now:** Local AI products increasingly mix local interfaces with remote services
- **Primary sources:** NIST Privacy Framework plus each product's own network/privacy documentation
- **Claims needing verification:** Product-specific behavior must be tested before publication
- **Target duration:** 75 seconds
- **Tone:** Clear, skeptical, useful
- **Possible demonstration:** Local endpoint configuration and telemetry toggle
