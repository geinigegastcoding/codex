OpenCV learning project

Count vehicles without an object detector

Fixed traffic video → motion → blobs → tracks → line crossing. Small enough to finish, deep enough to teach actual computer vision.

Strict scope

The finished project does one thing

Video→Foreground→Clean mask→Candidates→Track→Cross line→+1
Phase 1

Learn video as data

1
VideoCaptureRead frames, display them and exit correctly.
2
Frames + ROICoordinates, dimensions, crop to the road and place the count line.
Phase 2

Turn motion into vehicle candidates

3
Background subtractionLearn the static scene and expose changing foreground.
4
MorphologyClean noise and fragmented blobs.
5
ContoursGroup white blobs and reject implausible sizes.
6
CentersRepresent each candidate with a simple point.
The important jump
A detection is not a vehicle. The same vehicle is detected again in every frame. Tracking is what gives detections an identity across time.
Phase 3

Turn detections into tracks

Nearest-center matchingAssociate a new point with a nearby old track.
Track lifetimeSurvive short missed detections, but eventually forget departed cars.
Debug IDsDraw IDs and centers so identity swaps are visible rather than mysterious.
Phase 4

Count a transition, not proximity

Previous center above line→Current center below line→Track not counted→COUNT +1
Debug order

When the count is wrong, find the first broken layer

DetectionWas the vehicle represented by a useful blob/box?
TrackingDid that box keep the right identity across frames?
CountingDid that track genuinely transition across the line once?
Practice clip

You have a controlled test before the real video

The included synthetic clip has a known expected result of 6 crossings, plus distractors. That lets you diagnose your logic before fighting real-world noise.

Finish

Then move to the real traffic footage

Calibrate ROI → line → mask → candidate filters → tracker. Do not rewrite the entire algorithm because real footage is messier. The failures are part of what the project is supposed to teach.

Learning rule
There is no final solution file in the pack. Attempt → inspect → diagnose → Hint A → Hint B → Hint C.
